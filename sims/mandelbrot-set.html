What you're looking at

Each pixel is a complex number c. We repeatedly apply z → z² + c, starting from z = 0. If z stays bounded, c is inside the set (painted black). If z escapes to infinity, c is outside — and the colour shows how fast it escaped.

The boundary has infinite detail: no matter how far you zoom, there's always more structure. Try the Seahorse Valley preset to see spirals, or Mini Mandelbrot to find a tiny copy of the whole set hiding inside itself.
